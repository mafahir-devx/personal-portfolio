# 💻 Personal Portfolio Website

A simple personal portfolio website created as part of my Web Development assignment.

## 📌 About the Project

This website presents my personal profile, skills, projects, and contact information. It also includes a contact form with JavaScript-based client-side validation.

## 🛠️ Technologies Used

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript

## 📂 Website Sections

- 🏠 Home
- 👤 About Me
- 💡 Skills
- 🚀 Projects
- 📩 Contact Me

## 📬 Contact Form

The contact form includes:

- 👤 Full Name
- 📧 Email Address
- 📝 Subject
- 💬 Message

JavaScript is used to:

- ✅ Validate required fields
- 📧 Validate the email format
- 🔤 Check the minimum length of the subject
- 📝 Check the minimum length of the message
- ⚠️ Display validation error messages
- ✅ Display a success message
- 🚫 Prevent form submission when the information is invalid
